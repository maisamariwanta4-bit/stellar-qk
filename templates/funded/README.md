# {{PROJECT_NAME}}

A Stellar funded-account starter generated by [`stellar-qk`](https://github.com/YOUR_ORG/stellar-quickstart-kit).

## What it does

1. Generates a fresh ed25519 Stellar keypair
2. Funds the account on **Testnet** via [Friendbot](https://developers.stellar.org/docs/fundamentals-and-concepts/testnet-and-pubnet#friendbot)
3. Fetches and displays the opening XLM balance from Horizon

> **Note** — This requires an active internet connection and only works on Testnet/Futurenet.
> Friendbot is not available on Mainnet.

## Prerequisites

- Rust 1.74 or newer (`rustup update stable`)
- Internet access (to reach Friendbot and Horizon)

## Run

```bash
cargo run
```

Expected output:

```
=== Stellar funded starter (Testnet) ===

Public key  : GABC...
Secret seed : SABC...

⚠  Never share or commit your secret seed.

Funding account on Testnet via Friendbot…
✓ Funded!  tx hash: abc123...

Fetching balance from Horizon…

Asset                Balance
-----------------------------------
XLM                  10000.0000000

Done! Visit https://stellar.expert/explorer/testnet/account/GABC... to explore your account.
```
